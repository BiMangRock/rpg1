# 마왕 연대기

용사 일행을 처단하고 세상을 지배하는 2D 횡스크롤 액션 게임입니다.
브라우저에서 `index.html`을 열면 바로 플레이할 수 있어요 (설치 불필요).

## 조작

| 키 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 (S + 점프: 발판 아래로) |
| W | 포털 들어가기 |
| 좌클릭 (F) | 검 공격 — 커서 쪽으로 베기 |
| 우클릭 (E) | 마법 — 커서 방향으로 발사 |
| Q | 소환수 소환 (쿨타임 12초) |
| Esc | 일시정지 · 키 설정 |

클릭을 꾹 누르고 있으면 연속 공격합니다. 키는 타이틀/일시정지 화면의 "키 설정"에서 바꿀 수 있어요.

## 게임 요소

- **스테이지 3개**: 평화로운 마을 → 왕국의 성하 → 용사의 성전(보스)
- **레벨업 강화**: 공격력, 마법구체 수, 다단 점프, 소환수 수/강화 등
- **소환수**: 체력이 있고 적에게 공격받으면 죽습니다. 시간이 지나도, 포털을 지나도 사라지지 않고 죽을 때만 없어집니다 (최대 12마리, 꽉 찬 상태에서 소환하면 전원 체력 회복).
- **보스 · 각성한 용사**: 3페이즈 — 원형 탄막, 조준 검기, 돌진, 도약 충격파, 빛기둥, 졸개 소환

## 파일 구조

```
index.html          진입점
css/style.css       화면/메뉴 스타일
js/sprites.js       마왕 캐릭터·이펙트 스프라이트 프레임 정보
js/game.js          게임 로직 (입력, 적/보스 AI, 소환수, 렌더링)
assets/sprites/     스프라이트 PNG 이미지
```
