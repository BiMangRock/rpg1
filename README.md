# 마왕 연대기

용사 일행을 처단하고 세상을 지배하는 2D 횡스크롤 액션 게임입니다.
브라우저에서 `index.html`을 열면 바로 플레이할 수 있어요 (설치 불필요, 폴더째로 있어야 함).

## 조작

| 키 | 동작 |
|---|---|
| A / D | 좌우 이동 |
| Space | 점프 |
| S | 발판 아래로 내려가기 |
| W | 포털 들어가기 · 보물상자 열기 |
| 좌클릭 (F) | 검 공격 — 커서 쪽으로 베기 |
| 우클릭 (E) | 마법 — 커서 방향으로 발사 |
| Q | 소환수 소환 (쿨타임 12초) |
| I | 장비창 (보유 장비·유물·능력치, 장착 변경) |
| Esc | 일시정지 · 키 설정 |

클릭을 꾹 누르고 있으면 연속 공격합니다. 키는 타이틀/일시정지 화면의 "키 설정"에서 바꿀 수 있어요.

## 진행

```
1-1 → 1-2 → 1-3 → 1-4 → 1-5 → 1-보스(각성한 용사) → 유물 선택
2-1 → 2-2 → 2-3 → 2-4 → 2-5 → 2-보스(대주교 루미엘) → 승리
```
- 일반 적이 가끔 **★1~5 몬스터**로 등장 (깊은 스테이지일수록 자주, 높은 별일수록 강함)
  - 별 1개마다 체력 +100% (★1 = 2배, ★5 = 6배). 보상은 별 수의 제곱에 비례하고 ★4는 ×1.5, ★5는 ×2 추가 (★5 = 경험치·골드 약 30배)
  - **★4·★5는 마왕의 탄막(마법구체·검기·폭발)을 피함** (★4 35%, ★5 50%) — 피할 때 점프하며 옆으로 튕겨 나감
  - 경험치·골드는 양에 비례한 개수의 구슬·금화로 사방에 쏟아짐
  - 장비 드롭: ★1 8% · ★2 18% · ★3 32% · ★4 55% · **★5 확정 (+50% 확률로 1개 더, 20% 확률로 유물)**
  - 별이 많을수록 **특수 능력**: ★2 랜덤 1개 / ★3 용사갑옷(피해 -35%, 넉백 무시) / ★4 다단점프(공중 2회) / ★5 용사검기(3갈래 검기) + 랜덤
  - 랜덤 능력: 신속, 재생, 성방패, 순간이동, 분열(죽으면 2마리), 광폭(체력 50% 이하 강화), 호출(동료 2명 소환)
  - 마왕의 장비 특성도 사용: 빙결타(둔화), 화염타(화상), 독타(독 중첩), 흡혈, 가시(검 반사), 치명, 부활, 번개, 자폭
- 스테이지마다 40% 확률로 먼 곳에 **보물상자** (골드·경험치, 가끔 장비)
- 포털에 들어가면 **클리어 정산**: 맵에 남은 경험치·골드·장비 자동 획득 (수집가의 자루가 있으면 경험치·골드 2배), 이자, 클리어 경험치
- **매판 랜덤 맵**: 스테이지마다 지형이 새로 만들어짐 (보스전은 고정 아레나)
  - 평원: 가로로 긴 맵 → 포털은 오른쪽 끝
  - 고지: 가로·세로 모두 넓은 맵 → 포털은 가장 높은 발판
  - 탑: 좁고 높은 맵 → 포털은 꼭대기
  - 생성할 때 땅에서 포털까지 점프로 올라갈 수 있는지 검사하고, 안 되면 다시 생성
- 적은 발판 위에도 배치되고, **모든 지상 적이 발판을 뛰어오르내리며 추격** (2월드는 더 높고 자주). 궁수·지원형은 같은 층에 와서 거리를 둠
- 소환수도 발판을 따라오고 너무 멀면 순간이동
- 오른쪽 위 **미니맵**: 발판, 적(★몬스터는 금색), 포털, 보물상자, 현재 화면 범위 표시
- 스테이지를 클리어하고 포털에 들어가면 **정비 화면**이 열립니다: 상점 / 장비 / 유물 탭
- 보스를 쓰러뜨리면 **유물 3개 중 1개**를 골라 영구 효과를 얻습니다

## 시스템

- **레벨업**: 선택지 3개 중 **2개는 이미 고른 강화**, 1개는 랜덤 (빌드가 흩어지지 않게. 고른 게 적을 땐 랜덤으로 채움)

- **골드**: 적이 떨어뜨림. 상점에서 장비·회복 물약 구매
- **상점**: 맵이 바뀔 때마다 상품이 새로 바뀜. 🔓 **잠금**(가격의 10%)하면 사거나 풀 때까지 다음 맵에도 남음.
  새로고침은 누를 때마다 비싸짐 (20G → 30G → ...)
- **장비**: 무기 / 갑옷 / 장신구 3칸 (상점에서 최대 6칸까지 확장).
- **강화**: 정비 화면 [장비] 탭에서 가진 장비를 +1~+5 강화 (단계마다 효과 +25%, +3부터 마법구체·소환수 등 개수 +1).
- **회피**: 피해를 완전히 무시할 확률 (안개 반지, 그림자 망토, 헤르메스의 날개, 레벨업).
- 이동속도 장비: 쾌속 단검, 가벼운 깃털, 질풍의 발찌, 그림자 망토, 헤르메스의 날개, 바람신의 장화(유물)
- **등급**: ★ 일반 → ★★ 희귀(1-3부터) → ★★★ 전설(2월드부터)
- **경제 장비**: 수집가의 자루(자동 획득), 황금 거위 깃털(골드 2배), 은행가의 장부(이자), 상인의 인장(할인), 보물 지도, 네잎 클로버(★몬스터), 현상금 증표 등
- **특수 효과**: ❄빙결(일반 적 정지, 보스는 둔화) · 🔥화상 · ☠독 중첩 · ⚡연쇄 번개 · 검기 · 처형 · 💥시체 폭발 · 반격 · 부활
- **성장형 장비** (착용 중에만 쌓이고, 누적치는 장비에 남음. 장비 카드에 누적 표시):
  포식자의 심장(처치 시 최대 HP +1, 현재 HP는 그대로) · 오만의 왕관(풀피로 처치 시 최대 HP +2) · 흡혈귀의 성배(넘친 회복의 10% → 최대 HP) ·
  피에 젖은 칼날(처치 시 공격력 +0.2) · 사신의 장부(100킬마다 마법구체 +1, 최대 +5) · 사냥꾼의 트로피(★몬스터·보스 처치 시 랜덤 능력치 +5%) ·
  광전사의 흉터(피격마다 받는 피해 -0.5%, 최대 -30%) · 연쇄 학살(무피격 연속 처치 시 공속 스택, 맞으면 절반) ·
  영혼 항아리(영혼 500개 → 각성) · 마왕의 도감(종족별 처치 수만큼 그 종족에게 피해 증가, 50마리 완성마다 공격력 +3%) ·
  황금 우상(50G 쓸 때마다 랜덤 능력치 +2%) · 거인의 주먹(최대 HP 2% 추가 피해) · 살덩이 갑옷(최대 HP 100마다 받는 피해 -4%)
- **보석**: 절망·희망·증오·좌절의 보석. 장착 없이 영구 적용, **4개를 모두 모으면 무기·갑옷·장신구 칸 +1**.
  보스 처치 시 확정, ★4 8% · ★5 25% · 보물상자 6%로 드롭
- **유물**: 보스 클리어 보상. 장착 없이 영구 적용 (예: 불사의 심장 — 스테이지마다 1회 부활)
- **소환수**: 체력이 있고 적에게 공격받으면 죽습니다. 시간이 지나도, 포털을 지나도 사라지지 않음 (꽉 찬 상태에서 소환하면 전원 체력 회복)
  - 업그레이드가 **한 번에 소환하는 수**(기본 3)와 **최대 소환수**(기본 10)로 나뉨
  - 소환 계열 업그레이드를 고를 때마다 **소환 레벨 +1** → Lv 3·5·7·9에서 진화

    | 소환 Lv | 지상 | 공중 |
    |---|---|---|
    | 1 | 슬라임 | 박쥐 |
    | 3 | 해골 병사 | 유령 까마귀 |
    | 5 | 지옥견 (화상) | 가고일 (원거리) |
    | 7 | 흑기사 (범위 공격) | 와이번 (화염탄 2발) |
    | 9 | 심연 골렘 (범위 공격) | 흑룡 (화염탄 3발) |

## 검

- **기본 능력**: 회피(닌자·★4·5)와 보호막(수호 사제) 무시, 대주교의 성역을 뚫고 50% 피해
- **튕겨내기**: 화살·수리검·검기 등 적 탄환을 베면 쏜 적에게 되돌려 보냄
- **빙결 분쇄**: 얼어 있는 적을 베면 산산조각 → 추가 피해 + 주변 범위 피해
- **검 장비**: 연격의 쌍검(3연타 콤보: 3타째 강타·넉백·기절, 콤보마다 +10%), 낙하의 장화(공중 S+공격 내려찍기),
  질주의 검집(달리며 공격 → 돌진 관통 베기), 피의 맹세(검 흡혈), 검귀의 증표(검 처치 시 보상 +30%), 검성의 태도(전설)
- **검 레벨업**: 검술(검 피해 +30%), 넓은 베기(검 범위 +20%)

## 2월드 적

| 적 | 아이콘 | 능력 |
|---|---|---|
| 성직자 | ✚ | 주변 아군 체력 회복 |
| 군악 사제 | ♪ | 주변 아군 5초간 이동속도·공격력 증가 |
| 소환술사(법사) | ◆ | 정령 소환(빛·불·물·나무), 🔥화염구, 💧물결(점프로 넘기), 🌿가시덩굴(★2+), ☄불비(★3+) |
| 수호 사제 | ⬡ | 아군에게 보호막 (피해 흡수) |
| 광신도 | (빨간 두건) | 빠른 근접형, 발판을 뛰어올라 끝까지 추격 |
| 닌자 (2월드부터) | (검은 두건·붉은 머플러) | 탄막 회피 75% (검으로는 회피 불가), 수리검 투척, 공중 점프. 보상 큼: 경험치·골드 2배 이상, 12% 장비 드롭 |

지원형 적은 거리를 두고 뒤에서 돕기 때문에 먼저 처리하는 게 좋습니다.

- **원소 효과**: 불 = 화상(지속 피해), 물 = 둔화, 나무 = 독 중첩. 정령에 닿아도 같은 효과
- **★ 법사**: 별 1개마다 시전 간격 -20%(★5 약 2.2배 자주), 화염구·불비 발수와 정령 수 증가,
  ★3부터 한 번에 마법 2개 연속, ★5는 3개 연속. ★4부터 물결이 양쪽에서 밀려옴

## 보스

- **각성한 용사** (1월드): 원형 탄막, 조준 검기, 돌진, 도약 충격파(점프로 회피), 빛기둥
- **대주교 루미엘** (2월드): 공중 부유. 유도 빛구체, 텔레포트, 빛기둥, 빛의 비, 지원형 적 소환.
  페이즈 전환 시 **성역 수정**을 소환 — 수정을 모두 깨야 다시 피해를 줄 수 있음

## 파일 구조

```
index.html        진입점 (스크립트 로드 순서 중요)
css/style.css     화면/메뉴 스타일
js/sprites.js     마왕 캐릭터·이펙트 스프라이트 프레임 정보
js/data.js        ★ 밸런스 데이터: 스테이지, 적, 레벨업, 장비, 유물, 기본 키
js/core.js        공용 상태, 스탯 계산(레벨업+장비+유물), 스테이지 흐름
js/map.js         랜덤 맵 생성, 도달 가능성 검사, 중력/발판 물리, 점프 추격
js/combat.js      플레이어 공격, 피해 처리, 소환, 드롭, 레벨업
js/ai.js          적 AI, 지원형 적 스킬, 소환수 AI
js/boss.js        보스 패턴 (용사, 대주교)
js/update.js      매 프레임 갱신 (플레이어, 탄환, 드롭, 이펙트)
js/render.js      그리기 (배경, 캐릭터, 이펙트, HUD)
js/ui.js          메뉴 화면 (타이틀, 레벨업, 유물, 상점, 장비, 결과)
js/main.js        입력 처리, 게임 루프, 시작
assets/sprites/   스프라이트 PNG 이미지
```

새 장비나 유물을 추가하려면 `js/data.js`의 `ITEMS` / `RELICS` 배열에 한 줄 추가하면 됩니다.
새 월드는 `WORLDS`에 추가하고 `js/boss.js`의 `BOSS`에 보스를 등록하세요.
